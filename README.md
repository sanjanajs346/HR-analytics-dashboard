# 📊 HR Analytics Dashboard – Tableau

## 📌 Project Overview
An interactive HR Analytics Dashboard developed using Tableau to analyze employee data, workforce trends and employee attrition.

## 🛠️ Tools & Technologies
- Tableau
- Data Visualization
- Data Analysis

## 📈 Key Performance Indicators (KPIs)
- Total Employees: 1,470
- Active Employees: 1,233
- Attrition Count: 237
- Average Age: 36.92
- Average Salary: 6,503
- Attrition Rate: 16.1%

## 📊 Dashboard Features
- Attrition by Department
- Attrition by Gender
- Attrition by Age Group
- Attrition by Job Role
- Attrition by Education Field
- Job Satisfaction Analysis
- Employee Count by Department

## 🎯 Project Objective
To analyze employee attrition and workforce patterns, identify departments with higher employee turnover and provide insights for HR decision-making.
